THE VOICE — HOW JARVIS STOPS SOUNDING LIKE A COMPUTER

checking the local voice…

The real Jarvis voice is a cloned voice from VoiceStudio (Install 02 of the build pack). Until it is installed and open, he speaks in tiers: cloud tier first — Gemini's deep Charon voice or OpenAI's onyx, borrowed with an agent key you pasted above, 0 MB, no install — then the browser's stand-in voice (pick a better one any time from the VO menu under the dial). Four steps to the real clone, one time:

1 · installPowerShell: irm https://voicestudio.sh/install.ps1 | iex — then open the app
2 · runtimefirst run: click Install local runtime and wait — it downloads a few gigabytes once
3 · engineModel Catalogue → install and select VoxCPM2 (Windows, NVIDIA) · Mac: CSM 1B on the MLX audio engine
4 · cloneProfiles → New → Clone — a 10–20 second clean clip, one speaker, no music — name it exactly Jarvis

Keep the app open while Jarvis runs; he finds it on port 3900 by himself, pins the engine, and caches every line. Close it and he quietly falls back to the browser voice — nothing breaks.
